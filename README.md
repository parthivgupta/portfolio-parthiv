# portfolio-parthiv

Personal portfolio website for Parthiv Gupta, built with Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Search visibility

The canonical URL, social previews, structured data, robots.txt, and sitemap currently use `https://www.parthivv.info/`. If the site moves to another domain, update those URLs in `index.html`, `public/robots.txt`, and `public/sitemap.xml` together.

After deploying, verify the site in Google Search Console, inspect the home page, and submit `/sitemap.xml`. The sitemap includes the portrait used on the page. Check that the page and portrait URL are publicly accessible and not blocked from crawling. Search engines decide when to crawl and index the page and whether to show its image.
